A dip-buy swing bot that trades Coinbase Wrapped BTC (cbBTC) against USDC on 1-minute on-chain bars, built for make.fun's "Race a BTC trading bot live for 24 hours" bounty. It buys when the close falls 1.5% below its trailing 240-bar EMA, sells at +2.25% above the entry close or −1.5% below it, and stops entering in the last 120 bars so every position has time to reach its exit. Standard library only, fully deterministic.

## Run it

```sh
python3 -P -s main.py
```
